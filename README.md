# Duolingo Web App

A full-stack clone of the Duolingo web application: a learning path, a lesson player with
varied exercises, and the gamification loop (XP, streaks, hearts, gems, leagues and achievements).

- **Frontend:** Next.js (TypeScript) in [`frontend/`](frontend)
- **Backend:** FastAPI (Python) with SQLite in [`backend/`](backend)

> Educational clone built for a hiring assignment; not affiliated with Duolingo.

Setup, architecture, database schema and API documentation are added as the project is built.
